# محدوده پیاده‌سازی فاز اول

این بسته یک **هسته قابل اجرا برای MVP** است و تمام قابلیت‌های پیشرفته فاز اول را در سطح نهایی پیاده‌سازی نمی‌کند.

| قابلیت | آنچه واقعاً پیاده‌سازی شده | توسعه بعدی |
|---|---|---|
| معماری | ۷ سرویس مستقل به‌علاوه کتابخانه مشترک | استقرار و observability پیشرفته |
| هلدینگ | تعریف هلدینگ و شرکت با نوع فعالیت | مالکیت چندلایه، تلفیق و مشارکت |
| کاربران | ورود، رمز BCrypt، JWT و تخصیص نقش/شرکت | MFA، SSO، مدیریت نشست |
| امنیت | بررسی نقش و companyId در endpointها | مجوزهای ریزدانه و PostgreSQL RLS |
| ساختار سازمانی | دپارتمان با parent | نمودار سازمانی، پست و سمت |
| اطلاعات پایه | دسته‌بندی اختصاصی شرکت | فرهنگ داده و تعاریف پویا |
| گردش کار | درخواست و تأیید/رد یک مرحله‌ای | طراحی فرایندهای چندمرحله‌ای |
| اعلان | اعلان داخلی و وضعیت خوانده‌شدن | پیامک، ایمیل، صف |
| ممیزی | ثبت و جست‌وجوی رخداد با منبع JWT | audit غیرقابل‌دستکاری و outbox |

## دستور راه‌اندازی

در پوشه `erp-phase1` اجرا کنید:

```bash
python3 scripts/init_env.py
docker compose up -d --build
```

در ویندوز: `py scripts/init_env.py` و سپس `docker compose up -d --build`.

رمز راه‌اندازی برای حساب `admin` فقط در فایل `.env` روی سیستم شما ایجاد می‌شود.
